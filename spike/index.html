Phrase audio test

A test page for the French practice app. It plays real French audio on this phone and writes down everything that happens. Not the app itself.

What this is

  1. Paste the key Henning gave you (step 1) and pick a voice you like (step 2).
  2. Prepare the audio (step 3), then run the full test (step 4) four times, following the checklist.
  3. When done, tap Copy log at the bottom and send it back.

1The key

No key yet. The key stays on this phone only, and is forgotten when you close this tab. It never appears in the log.

2Pick a voice

Tap “Hear the phrases” for each voice and pick the one that sounds best speaking French. Hold the phone at arm’s length, like you would while practising.

First listen per voice takes a little while — the audio is being made. After that it is instant.

3Prepare the full test

4The full test — four runs

  1. Run 1 — leave it alone. Tap Start and let it play all the way to the end (about 3 minutes). Keep the screen on. Listen for any phrase that never plays or any silence that goes on too long.
  2. Run 2 — lock the screen. Start again. While a phrase is playing, press the side button to lock the phone. Wait about 15 seconds, then unlock. Note whether the sound stopped, and whether it came back.
  3. Run 3 — the ringer switch. Start again. While a phrase is playing, flip the orange ringer/silent switch on the side of the phone. Does the sound stop? Flip it back — does it return?
  4. Run 4 — switch apps. Start again. While it plays, swipe to another app for a few seconds, then come back.
